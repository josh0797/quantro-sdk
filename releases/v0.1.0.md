# Quantro SDK 0.1.0

Primera distribución pública de `@quantroos/sdk` mediante GitHub Releases.
Acceso anticipado; la API puede cambiar entre versiones menores.

## Instalación

```bash
npm install https://github.com/josh0797/quantro-sdk/releases/download/v0.1.0/quantroos-sdk-0.1.0.tgz zod
```

La CLI instalada se ejecuta con `npx --no-install quantro help`.

## Contenido y verificación

- Node.js 20+, módulos ESM, tipos TypeScript y licencia MIT.
- Herramientas con schemas Zod, proveedor MCP y verificación HMAC-SHA256.
- Límites de solicitud, validación temporal de firmas y caché de ejecuciones
  dentro del proceso.
- 76 pruebas del SDK aprobadas, más typecheck, build y comprobación del paquete.
- Paquete de 19 archivos: 22,199 bytes comprimidos, 60,539 bytes sin comprimir.
- Distribución exclusiva del SDK: no incluye el código ni el historial del
  producto Quantro.

El archivo es idéntico al artefacto verificado previamente. No se modificó su
nombre, versión ni contenido al cambiar el canal de distribución.

## Limitaciones

- No publicado en npmjs.com: instala desde la URL de GitHub, no por nombre.
- El README incluido en el paquete y la ayuda de la CLI conservan ejemplos
  del canal npm. Sigue las instrucciones de esta release para instalarlos y
  ejecutar la CLI local.
- Las dependencias continúan descargándose desde npm; este canal sustituye
  la publicación del SDK, no el origen de todas sus dependencias.
- La caché de idempotencia no es persistente ni compartida entre réplicas.
- No se ha verificado una conexión con una cuenta de Quantro en producción
  como parte de esta publicación.
